Send the request to the secure hostname for the mode of your API key. The secure hostname turns the card into a token before the request reaches the Credova API.

| Mode | Hostname | API key |
|------|----------|---------|
| Live | `https://secure.payments.credova.com` | Live `Secret Key` |
| Test | `https://secure-test.payments.credova.com` | Test mode `Secret Key` |

<Alert type="warning">Use the hostname that matches the mode of your API key. Each hostname saves the card for its own mode, so a key from the other mode makes the request fail.</Alert>

Put the card in `payment_method.card_details`:

| Field | Required | Description |
|-------|----------|-------------|
| `cardholder_name` | Yes | Name on the card. |
| `number` | Yes | Card number, digits only. |
| `expiration_month` | Yes | Expiration month, from `1` to `12`. |
| `expiration_year` | Yes | Four-digit expiration year. |
| `cvc` | No | Card security code. A card sent without a CVC can decline more often. |

The request also needs `customer` (or `customer.customer_id`) and `billing_details`. The rest of the body is the same as a request to `https://api.publicsquare.com`.
