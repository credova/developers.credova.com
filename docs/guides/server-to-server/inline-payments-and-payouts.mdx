# Inline Card Payments and Payouts

Send the card details in the same request that creates the payment or payout. You do not need to save the card first. The card is saved to the customer, and the response gives you its `id` for later payments and payouts.

<Alert type="warning">Your servers receive and send cardholder data in this flow, so your organization must be PCI certified. If you are unsure, please [reach out for support](mailto:support@publicsquare.com). To keep card data out of your servers, use [Accept Card Payments](/guides/browser/accept-card-payments) for payments and [Send Payouts](/guides/payouts/send-payouts) for payouts.</Alert>

<Alert>Inline card details work with [Create Payment](/api/financial/create-payment). Payment Intents do not accept `card_details`.</Alert>

## Getting Started

<GettingStartedSection />

### Get your Secret Key

Next you will need your `Secret Key`. [Go to your Developers section](https://portal.publicsquare.com/developers/api-keys) and click `Reveal` for your `Secret Key` and copy the value.

<Alert>A restricted key needs the `payment-method:write` or `payment-method:capture` permission, in addition to the permission to create payments or payouts.</Alert>

## Process a Payment

A payment with `card_details` also needs `device_information.ip_address`, the IP address of the customer's device.

### Create a Payment

```shell showLineNumbers title="Create a Payment with Inline Card Details"
curl 'https://secure.payments.credova.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    // highlight-start
    "card_details": {
      "cardholder_name": "John Smith",
      "number": "4242424242424242",
      "expiration_month": 12,
      "expiration_year": 2030,
      "cvc": "123"
    }
    // highlight-end
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  },
  "device_information": {
    "ip_address": "203.0.113.10"
  }
}'
```

<Alert>The amount is provided in cents. 1000 is the equivalent of $10.00</Alert>

To test, send the same request to `https://secure-test.payments.credova.com` with your test mode `Secret Key` and a [test card](/api/testing#cards).

### Verify a Card

To check a card without charging it, send a [verification payment](/guides/payments/verify-cards) with `card_details`. Set `amount` to `0`, `capture` to `false` and `verification.type`:

```shell showLineNumbers title="Verify a Card with Inline Card Details"
curl 'https://secure.payments.credova.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 5f0c1f3e-2f5b-4d7e-9b7e-0b8d1c6f4a21' \
-H 'Content-Type: application/json' \
-d '{
  // highlight-start
  "amount": 0,
  "capture": false,
  "verification": {
    "type": "add_card"
  },
  // highlight-end
  "currency": "USD",
  "payment_method": {
    "card_details": {
      "cardholder_name": "John Smith",
      "number": "4242424242424242",
      "expiration_month": 12,
      "expiration_year": 2030,
      "cvc": "123"
    }
  },
  "customer": {
    "customer_id": "cus_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  },
  "device_information": {
    "ip_address": "203.0.113.10"
  }
}'
```

-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
