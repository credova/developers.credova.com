# Create a Payment with Card Details

Send the card details in the same request that creates the payment. You do not need to save the card first. The API saves the card to the customer and returns its `id` for later payments.

<Alert type="warning">Your servers receive and send cardholder data in this flow, so your organization must be PCI certified. If you are unsure, please [contact support](/support). To keep card data out of your servers, use [Accept Card Payments](/guides/payments/elements/accept-card-payments).</Alert>

<Alert>We recommend [Payment Intents](/concepts/payment-intents) for new integrations. They retry safely and report slow processors by webhook. Payment Intents do not accept `card_details`, so [save the card](/guides/payments/direct-api/save-cards) first and [create the intent](/guides/payments/elements/accept-card-payments#create-a-payment-intent) with the card `id`. Use `card_details` with [Create Payment](/api/financial/create-payment) when you want to send the card and charge it in one request.</Alert>

To send a payout with card details, see [Send Card Payouts](/guides/payouts/process-card-payouts#create-with-card-details).

## Process a Payment

A payment with `card_details` also needs `device_information.ip_address`, the IP address of the customer's device.

### Create a Payment

```shell showLineNumbers title="Create a Payment with Card Details"
curl 'https://secure.payments.credova.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    // highlight-start
    "card_details": {
      "cardholder_name": "John Smith",
      "number": "4242424242424242",
      "expiration_month": 12,
      "expiration_year": 2030,
      "cvc": "123"
    }
    // highlight-end
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  },
  "device_information": {
    "ip_address": "203.0.113.10"
  }
}'
```

<Alert>The amount is provided in cents. 1000 is the equivalent of $10.00</Alert>

To test, send the same request to `https://secure.payments.sbx.credova.com` with your test mode `Secret Key` and a [test card](/guides/testing#cards).

### Create with Existing Customer

If you [created a customer](/api/accounts/create-customer), pass its ID as `customer.id`:

```shell showLineNumbers title="Create a Payment with Customer"
curl 'https://secure.payments.credova.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \

-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,

      "cardholder_name": "John Smith",
      "number": "4242424242424242",

    }
  },
  "customer": {
    // highlight-next-line
    "id": "cus_7Ay5mcUXAxwrN6wQEQUVEHBCJ"

  "billing_details": {
    "address_line_1": "111 Test St.",

    "country": "US"

}'
```

### Verify a Card

To check a card without charging it, send a [verification payment](/guides/payments/verify-cards) with `card_details`. Set `amount` to `0`, `capture` to `false` and `verification.type`:

```shell showLineNumbers title="Verify a Card with Card Details"
curl 'https://secure.payments.credova.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 5f0c1f3e-2f5b-4d7e-9b7e-0b8d1c6f4a21' \
-H 'Content-Type: application/json' \
-d '{
  // highlight-start
  "amount": 0,
  "capture": false,
  "verification": {
    "type": "add_card"
  },
  // highlight-end
  "currency": "USD",
  "payment_method": {
    "card_details": {
      "cardholder_name": "John Smith",
      "number": "4242424242424242",
      "expiration_month": 12,
      "expiration_year": 2030,
      "cvc": "123"
    }
  },
  "customer": {
    "id": "cus_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  },
  "device_information": {
    "ip_address": "203.0.113.10"
  }
}'
```
