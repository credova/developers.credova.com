# Accept Bank Account Payments

This guide processes an ACH payment from your server with a saved bank account or with bank account details. Save the bank account first with [Save Bank Accounts](/guides/payment-methods/bank-accounts).

## Before you start

<BeforeYouStart keys={["secret"]} />

## Process the Payment

Use the bank account you saved by [manual entry](/guides/payment-methods/bank-accounts#manual-entry) or [instant verification](/guides/payment-methods/bank-accounts#instant-verification) to create a new payment.

Use the `id` of the collected bank account, such as `ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ`, as the `bank_account` value in the payment.

### Create a Payment

We need to make a call to [Create Payment](/api/financial/create-payment) endpoint:

```shell showLineNumbers title="Create a Payment"
curl 'https://api.publicsquare.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

<Alert>The amount is provided in cents. 1000 is the equivalent of $10.00</Alert>

<Alert type="warning">The IDEMPOTENCY-KEY header can be passed to protect against duplicate payments being processed.</Alert>

### Create with Bank Account Details

If you have not saved the bank account yet, you can send its details with the payment. The API saves the bank account and charges it in the same request, so you do not need to call [Create Bank Account](/api/financial/create-bank-account) first.

Before you use `bank_account_details`:

- Your account must have the `payment-methods:bank-accounts:manual-creation` account setting. See [Request Account Setting Access](/guides/payment-methods/bank-accounts#request-account-setting-access).
- A restricted API key must have the `payment-method:write` permission in addition to `payment:write`. Secret keys have all permissions.

```shell showLineNumbers title="Create a Payment with Bank Account Details"
curl 'https://api.publicsquare.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "bank_account_details": {
      "account_holder_name": "John Doe",
      "account_holder_type": "individual",
      "account_type": "checking",
      "routing_number": "110000000",
      "account_number": "000123456789"
    }
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

- `bank_account_details` accepts the same fields as [Create Bank Account](/api/financial/create-bank-account).
- Include `account_holder_name` and `account_holder_type`. Some processors require them.
- You cannot combine `bank_account_details` with `bank_account`, `card`, `apple_pay`, or `google_pay`.
- If you omit the top-level `customer` or `billing_details`, the payment uses the `customer_id` and `billing_details` inside `bank_account_details`.
- The response returns the saved bank account in `payment_method.bank_account`. Use its `id` as `bank_account` for later payments.
- [Payment intents](/concepts/payment-intents) accept `bank_account_details` when you create the intent. An update request with `bank_account_details` returns a 400.

<Alert type="warning">
  Send an `IDEMPOTENCY-KEY` with each request. If a request fails and you retry it with the same key, the payment uses the bank account that the first
  request saved. A retry with the same key and different bank account details returns a 400. Use a new key when you change the bank account details.
</Alert>

```json showLineNumbers title="Retry with different bank account details"
{
  "title": "Error",
  "status": 400,
  "detail": "'bank_account_details' differs from the request first sent with this IDEMPOTENCY-KEY."
}
```

### Create with Existing Customer

If you [created a customer](/api/accounts/create-customer), then you can pass its ID as `customer.id` when processing the payment:

```shell showLineNumbers title="Create a Payment with Customer"
curl 'https://api.publicsquare.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "customer": {
    "id": "cus_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

```shell showLineNumbers title="Create a Payment with Payment Method"
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",

```

### Create with Payment Method's Billing Details

If you supplied the `billing_details` or [updated the bank account](/api/financial/update-bank-account), then you can omit the `billing_details` section when processing the payment:

```shell showLineNumbers title="Create a Payment with Payment Method"
curl 'https://api.publicsquare.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  }
}'
```

## Payment Status

ACH payments do not settle instantly. A new ACH payment has the `pending` status. When the bank transfer settles, the payment moves to `succeeded`.
Subscribe to the [`payment:update` webhook](/concepts/webhooks) to receive each status change.

If the bank rejects the debit, the payment moves to `declined`. The `declined_reason` field contains the ACH return code and its description:

```json showLineNumbers title="Declined ACH payment"
{
  "id": "pmt_2YKewBonG4tgk12MheY3PiHDy",
  "status": "declined",
  "declined_reason": "R02 - Account Closed"
}
```

Some return codes also change the bank account's `status` to `closed` or `invalid`. A new payment with that bank account returns a 400 with
`bank account has 'closed' status.` See [Bank Accounts](/concepts/bank-accounts#statuses), and collect a new bank account from the customer.

You can [refund](/guides/refunds/refund-payments) an ACH payment after it reaches `succeeded`.
