# Accept Google Pay

This guide creates a payment from your server with a Google Pay payment method. Save the payment method first with [Set Up Google Pay](/guides/payment-methods/google-pay).

## Before you start

<BeforeYouStart keys={["secret"]} />

## Process the Payment

Use the `id` of a saved Google Pay payment method to create a payment. Your frontend sends the `id` to your backend, as in the `chargePayment` call in [Set Up Google Pay](/guides/payment-methods/google-pay#tokenization-and-storing-google-pay), and your backend makes the call with your [Secret Key](#before-you-start).

For example, given the Google Pay payment method `ggl_Aw3U2eESBnq6DoYEFn8qaSMrA` from the previous step:

### Create a Payment

We need to make a call to [Create Payment](/api/financial/create-payment) endpoint:

```shell showLineNumbers title="Create a Payment"
curl 'https://api.publicsquare.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "google_pay": "ggl_Aw3U2eESBnq6DoYEFn8qaSMrA"
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

<Alert>The amount is provided in cents. 1000 is the equivalent of $10.00</Alert>

<Alert type="warning">The IDEMPOTENCY-KEY header can be passed to protect against duplicate payments being processed.</Alert>

### Create with Existing Customer

If you [created a customer](/api/accounts/create-customer), then you can pass its ID as `customer.id` when processing the payment:

```shell showLineNumbers title="Create a Payment with Customer"
curl 'https://api.publicsquare.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "google_pay": "ggl_Aw3U2eESBnq6DoYEFn8qaSMrA"
  },
  "customer": {
    "id": "cus_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

### Create with Customer's Payment Method

If you [attached the Google Pay payment method to a customer](/api/financial/attach-google-pay-to-customer), then you can omit the `customer` section when processing the payment:

```shell showLineNumbers title="Create a Payment with Payment Method"
curl 'https://api.publicsquare.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "google_pay": "ggl_Aw3U2eESBnq6DoYEFn8qaSMrA"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

### Create with Payment Method's Billing Details

If you supplied the `billing_details` or [updated the Google Pay payment method](/api/financial/update-google-pay-payment-method), then you can omit the `billing_details` section when processing the payment:

```shell showLineNumbers title="Create a Payment with Payment Method"
curl 'https://api.publicsquare.com/payments' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "google_pay": "ggl_Aw3U2eESBnq6DoYEFn8qaSMrA"
  }
}'
```
