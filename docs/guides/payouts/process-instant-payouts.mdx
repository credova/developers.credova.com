# Process Instant Payouts

Instant payouts send funds to a bank account over real-time payment rails and typically settle within minutes, instead of the multi-day timeline of a [standard ACH payout](/guides/payouts/process-ach-payouts). Instant payouts require the `payouts:instant` account setting to be enabled before you can use them.

## Getting Started

<GettingStartedSection />

### Get your Secret Key

Next you will need your `Secret Key`. [Go to your Developers section](https://portal.publicsquare.com/developers/api-keys) and click `Reveal` for your `Secret Key` and copy the value.

<Alert>Save the Secret Key as it will be used in the next steps of this guide.</Alert>

## Request Account Setting Access

First, you will need to request access to the `payouts:instant` account setting type.

To do this, go to the [merchant portal](https://portal.publicsquare.com/settings/features) and click on the `Request this feature` button next to the `Instant Payouts` setting.
Alternatively, you can request access via the [API](/api/accounts/request-account-setting-access).

This is required to enable instant payouts for your account.

## Process the Payout

We will need a bank account payment method to send the instant payout to. If you haven't already, complete the [Collect Verified Bank Accounts](/guides/payment-methods/collect-verified-bank-accounts) guide first — a verified bank account is the more reliable choice for a real-time transfer.

### Create a Payout

We need to make a call to [Create Payout](/api/financial/create-payout) endpoint with `payout_type` set to `instant`:

```shell showLineNumbers title="Create an Instant Payout"
curl 'https://api.publicsquare.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPONTENCY-KEY: '09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  // highlight-next-line
  "payout_type": "instant",
  "payment_method": {
    "bank_account": "ba_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

<Alert>The amount is provided in cents. 1000 is the equivalent of $10.00</Alert>

<Alert type="warning">The IDEMPONTENCY-KEY header can be passed to protect against duplicate payouts being processed.</Alert>

<Alert type="warning">If the `payouts:instant` account setting has not been enabled for your account, this request will fail. See [Request Account Setting Access](#request-account-setting-access) above.</Alert>

For the `customer_id`, existing payment method, and existing billing details request variants, see the equivalent sections in [Process ACH Payouts](/guides/payouts/process-ach-payouts#create-with-existing-customer) — they work the same way for instant payouts, just add `"payout_type": "instant"` to the request body.

## Handling Declines

If an instant payout is declined, the response's `declined_reason` will contain the reason available at the time of the decline. The linked bank account's `status` may also change as a result of the decline. See [Bank Accounts](/concepts/bank-accounts#statuses).
