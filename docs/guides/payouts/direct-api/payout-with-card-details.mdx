# Send a Payout with Card Details

Send the card details in the same request that creates the payout. You do not need to save the card first. The API saves the card to the customer and returns its `id` for later payouts.

<Alert type="warning">Your servers receive and send cardholder data in this flow, so your organization must be PCI certified. If you are unsure, please [contact support](/support). To keep card data out of your servers, use a saved card as shown in [Send Card Payouts](/guides/payouts/process-card-payouts).</Alert>

To create a payment with card details, see [Create a Payment with Card Details](/guides/payments/direct-api/payment-with-card-details).

## Before you start

<BeforeYouStart keys={["secret"]}>
A restricted key needs the `payment-method:write` or `payment-method:capture` permission, in addition to `payout:write`.
</BeforeYouStart>

## Process a Payout

A payout with `card_details` does not need `device_information`.

### Create a Payout

```shell showLineNumbers title="Create a Payout with Card Details"
curl 'https://secure.payments.credova.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    // highlight-start
    "card_details": {
      "cardholder_name": "John Smith",
      "number": "4242424242424242",
      "expiration_month": 12,
      "expiration_year": 2030,
      "cvc": "123"
    }
    // highlight-end
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

<Alert>The amount is provided in cents. 1000 is the equivalent of $10.00</Alert>

To test, send the same request to `https://secure.payments.sbx.credova.com` with your test mode `Secret Key` and a [test card](/guides/testing#cards).

### Create with Existing Customer

If you [created a customer](/api/accounts/create-customer), pass its ID as `customer.id`:

```shell showLineNumbers title="Create a Payout with Customer"
curl 'https://secure.payments.credova.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "card_details": {
      "cardholder_name": "John Smith",
      "number": "4242424242424242",
      "expiration_month": 12,
      "expiration_year": 2030,
      "cvc": "123"
    }
  },
  "customer": {
    // highlight-next-line
    "id": "cus_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",

    "country": "US"
  }
}'
```

For the next payout with this card, send `"payment_method": { "card": "<card id>" }` to `https://api.publicsquare.com/payouts`, as in [Send Card Payouts](/guides/payouts/process-card-payouts). A saved card is a token, so this request does not need the secure hostname.
