# Process Inline Card Payouts

Send the card details in the same request that creates the payout. You do not need to save the card first. The card is saved to the customer, and the response gives you its `id` for later payouts.

<Alert type="warning">Your servers receive and send cardholder data in this flow, so your organization must be PCI certified. If you are unsure, please [reach out for support](mailto:support@publicsquare.com). To keep card data out of your servers, use [Collect Cards](/guides/payment-methods/collect-cards) and [Process Card Payouts](/guides/payouts/process-card-payouts).</Alert>

## Getting Started

<GettingStartedSection />

### Get your Secret Key

Next you will need your `Secret Key`. [Go to your Developers section](https://portal.publicsquare.com/developers/api-keys) and click `Reveal` for your `Secret Key` and copy the value.

<Alert>A restricted key needs the `payment-method:write` or `payment-method:capture` permission, in addition to the permission to create payouts.</Alert>

## Process the Payout

A payout with `card_details` does not need `device_information`.

<InlineCardDetailsSection />

### Create a Payout

```shell showLineNumbers title="Create a Payout with Inline Card Details"
curl 'https://secure.payments.credova.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    // highlight-start
    "card_details": {
      "cardholder_name": "John Smith",
      "number": "4242424242424242",
      "expiration_month": 12,
      "expiration_year": 2030,
      "cvc": "123"
    }
    // highlight-end
  },
  "customer": {
    "first_name": "John",
    "last_name": "Smith",
    "email": "john.smith@email.com"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

<Alert>The amount is provided in cents. 1000 is the equivalent of $10.00</Alert>

To test, send the same request to `https://secure.payments.sbx.credova.com` with your test mode `Secret Key` and a [test card](/api/testing#cards).

### Create with Existing Customer

If you [created a customer](/api/accounts/create-customer), pass its ID as `customer.id`:

```shell showLineNumbers title="Create a Payout with Customer"
curl 'https://secure.payments.credova.com/payouts' \
-X 'POST' \
-H 'X-API-KEY: <SECRET_API_KEY>' \
-H 'IDEMPOTENCY-KEY: 09ec2c87-7fb8-44ca-bb18-5c71a76974da' \
-H 'Content-Type: application/json' \
-d '{
  "amount": 1000,
  "currency": "USD",
  "payment_method": {
    "card_details": {
      "cardholder_name": "John Smith",
      "number": "4242424242424242",
      "expiration_month": 12,
      "expiration_year": 2030,
      "cvc": "123"
    }
  },
  "customer": {
    // highlight-next-line
    "id": "cus_7Ay5mcUXAxwrN6wQEQUVEHBCJ"
  },
  "billing_details": {
    "address_line_1": "111 Test St.",
    "city": "Des Moines",
    "state": "IA",
    "postal_code": "51111",
    "country": "US"
  }
}'
```

Store `payment_method.card.id`. For the next payout to this card, send `"payment_method": { "card": "<card id>" }` to `https://api.publicsquare.com/payouts`, as in [Process Card Payouts](/guides/payouts/process-card-payouts). A saved card is a token, so this request does not need the secure hostname.
