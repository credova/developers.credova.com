# Support

Email the Credova payments support team for help with your integration, your account, or a transaction.

**Email:** [payment-support@publicsq.com](mailto:payment-support@publicsq.com)

## Include these details

Send these details with your first message. They help us find the problem faster.

- Your account ID, and whether the issue is in the `Test` or `Production` environment.
- The endpoint, HTTP status code, and response body of the failed request.
- The correlation ID of the request. See [Request Correlation](/api/request-correlation).
- The date and time of the request, with the time zone.
- The ID of the payment, payout, or payment intent, if the issue is about one.
- For an Elements issue, the SDK version and the browser.

Never send API keys, full card numbers, or full bank account numbers.

## Before you write

Many issues have a known cause. Check these pages first:

- [Errors](/api/errors) lists each error code and how to fix it.
- [Testing](/api/testing) lists test cards, test hostnames, and simulated declines.
- [Production checklist](/guides/production-checklist) lists what to confirm before you go live.
