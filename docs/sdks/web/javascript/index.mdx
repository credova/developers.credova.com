# JavaScript Elements SDK

<GithubCard heading="JavaScript Elements SDK" icon={SDK.JAVASCRIPT} organization="credova" repository="elements" />

The PublicSquare JavaScript SDK makes it easy to build secure web applications that collect cardholder data using Elements.

Get started with our [guide](/guides/payments/elements/accept-card-payments).

## Before You Begin

This SDK requires the use of a Publishable API Key. [Go to your Developers section](https://portal.publicsquare.com/developers/api-keys) and click `Reveal` for your `Publishable Key` and copy the value.

## Versions

Install the latest version unless you need to pin one. The current release is <LatestVersion pkg="@publicsquare/elements-js" />. See the [changelog](/sdks/web/changelog) for release notes.

### Version compatibility

Version 1.16.1 and later work with test mode against a production account. Earlier versions do not support it. From 1.16.1, Elements detects your environment from your Publishable Key, so use the key that matches your environment.

### If using the CDN

Elements is also available via CDN at `https://js.publicsquare.com/index.js`. This URL always serves the latest release.

To pin a version instead, replace `<version>` with a release number such as `1.16.1`:

```html showLineNumbers
<script src="https://js.publicsquare.com/v<version>/index.js"></script>
```

### If using npm

Check your installed version:

```shell showLineNumbers
npm list @publicsquare/elements-js
```

To pin a version, replace `<version>` with a release number such as `1.16.1`:

## Initialization

```javascript showLineNumbers
import { PublicSquare } from "@publicsquare/elements-js";

// In this context PublicSquare is a class
const publicsquare = await new PublicSquare().init("<PUBLISHABLE_API_KEY>");
// use Elements
```

| Parameter | Required | Type                     | Description                     |
| --------- | -------- | ------------------------ | ------------------------------- |
| `apiKey`  | true     | _string_                 | The Publishable API Key         |

<Alert type={Alerts.WARNING}>If you try to to use any Elements feature before calling <code>PublicSquare.init</code>, or before its Promise has been fulfilled, you will get an error.</Alert>
